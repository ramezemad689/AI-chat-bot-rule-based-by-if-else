# AI Chatbot (Rule-Based using If-Else)
## Overview

This is a simple rule-based chatbot built using Python and conditional statements (if-else). The chatbot responds to user inputs by matching predefined keywords and returning fixed responses.

## How It Works

The chatbot takes user input, checks it against a set of predefined rules, and returns the corresponding response. If no match is found, it returns a default message.

## Features

* Simple conversational responses
* Keyword-based input handling
* Lightweight and easy to run
* Beginner-friendly Python implementation

## Technologies Used

* Python
* Basic programming concepts (if-else, strings, loops)

## Project Structure

* `AI chat-bot rule-based by if-else (DecodeLabs).py` → Main chatbot script
* `AI chatbot notes.txt` → Notes / extra information

## How to Run

1. Install Python
2. Open terminal in project folder
3. Run:

   ```bash
   python "AI chat-bot rule-based by if-else (DecodeLabs).py"
   ```
 Limitations
* No machine learning or NLP
* Cannot understand context or intent
* Works only with predefined inputs
